# Upstream attribution

This package carries the built browser AppFrame from `@deepseek-ai/dsh-client-ui-layout@0.2.2-rc.1`, DeepSeek AI, https://github.com/deepseek-ai/deepseek-harness, licensed MIT. The upstream registration name and its hardcoded product-title constant are the only substitutions. UI slots, layout navigation, session projection, accessibility and sizing code remain unchanged. `UPSTREAM.json` records hashes. `scripts/build-naumi-layout.mjs` recreates and verifies this artifact from the pinned installed package; it never edits node_modules.
