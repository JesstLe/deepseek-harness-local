## 公共接口、依赖方向、数据/状态归属

- 身份由 Canvas API 管理；企业协作连接单独授权。账号首次登录、尚未配置企业协作时，不创建企业连接，也不阻止本地工作台启动。

## 调研结论、本次实现与迁移状态

1. 发版检查发现 `desktopCollaborationOrigin` 在未连接企业协作的全新账号目录强读不存在的 `desktop-enterprise.json`。真实模块基线复现 `ACCOUNT_ONLY_STARTUP=ENOENT`，exit 1；此前身份 E2E 使用 backend adapter，未覆盖该组装链。
2. 最小修复：仅在既没有声明 enterprise origin、也没有既有绑定时采用已校验的界面默认 origin；不写连接、不生成登录态。原生有限桥仍拒绝无企业会话的数据请求；已有绑定仍必须与环境中的 issuer 精确一致。
3. 新增三项启动/issuer/未授权边界测试；发布包使用隔离账号 API fixture、真实打包主进程/预加载和真实内置后端进行登录启动与检查更新验收。无真实账号密码或模型调用。
4. 输出到版本专属 `runtime/naumi-desktop-release-0.3.4`，不覆盖被现有窗口使用的旧目录。
